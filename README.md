# 🐔 Sistema de Administração de Granja

[![Java](https://img.shields.io/badge/Java-17-orange.svg)](https://www.java.com/)
[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.2-brightgreen.svg)](https://spring.io/projects/spring-boot)

> Sistema completo para gerenciamento de animais e controle financeiro de granjas. Projeto desenvolvido para demonstrar competências em Java Spring Boot, boas práticas de desenvolvimento e arquitetura MVC

---

## 📋 Sobre o Projeto

O **Granja Admin Sistema** é uma aplicação web que permite gerenciar de forma simples e eficiente:

- ✅ **Cadastro e controle de animais** (bovinos, galinhas, porcos, ovelhas, etc.)
- ✅ **Registro de alimentação** e acompanhamento nutricional
- ✅ **Controle de saúde** (vacinas, tratamentos, consultas veterinárias)
- ✅ **Gestão financeira** (receitas, despesas, fluxo de caixa)
- ✅ **Relatórios e dashboard** para tomada de decisões

---

## 🛠️ Tecnologias Utilizadas

### Backend
| Tecnologia | Versão | Finalidade |
|------------|--------|------------|
| Java | 17 | Linguagem principal |
| Spring Boot | 3.2.x | Framework backend |
| Spring Data JPA | - | Persistência de dados |
| Hibernate | - | ORM (Mapeamento Objeto-Relacional) |
| MySQL | 8.0 | Banco de dados relacional |
| Maven | 3.9+ | Gerenciador de dependências |
| Jakarta Validation | - | Validações de entrada |

### Frontend (Em desenvolvimento)
| Tecnologia | Finalidade |
|------------|------------|
| React.js | Interface do usuário |
| Material UI | Componentes visuais |
| Axios | Requisições HTTP |

### Ferramentas
- **IDE**: Eclipse 
- **Versionamento**: Git + GitHub
- **API Testing**: Postman / Insomnia
- **Modelagem**: Draw.io / Lucidchart
